Visão Geral

O OVITO é voltado à análise e ao render de simulações atomísticas em larga escala, lendo os formatos de trajetória mais usados e oferecendo um conjunto de modificadores de dados — análise de estrutura local, identificação de defeitos, vetor de deslocamento, seleção por propriedade, vínculo covalente e criação de superfícies — combináveis em pipeline executável sobre todos os quadros. A interface gráfica permite animar e renderizar, com motor embutido ou saída para POV-Ray; há também API Python e versão em linha de comando para scripts.

Principais Recursos

  • Modificadores de análise e pipeline de dados
  • Identificação de estrutura local e defeitos
  • Seleção e coloração por propriedade atômica
  • Animação e render de alta qualidade
  • API Python e versão sem interface gráfica
